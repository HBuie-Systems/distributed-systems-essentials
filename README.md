# Distributed Systems Essentials

A high-signal implementation of core distributed patterns using **Dapr** and **Python**. This repository is architected for minimal boilerplate and maximum clarity—optimized for **Gemini's long-context window** to ensure 100% architectural visibility during complex AI design discussions and interactions.

## 🏗️ Architecture & Features

- **Python-First:** Focused purely on clean, idiomatic Python implementations.
- **Service Invocation:** Demonstrates robust service-to-service communication.
- **Validated Models:** Uses Pydantic for strict Order/OrderItem validation (Phase 2.0).
- **AI-Optimized:** Pruned of legacy boilerplate to maximize LLM context window efficiency.
